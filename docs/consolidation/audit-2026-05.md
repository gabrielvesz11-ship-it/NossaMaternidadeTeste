# Consolidation Audit - May 2026

## Decision

`NossaMaternidadeTeste` is the canonical repository for Nossa Maternidade.

After the old public `NossaMaternidade` duplicate is archived or renamed, this repository should be renamed to `NossaMaternidade`.

## Why

The account contains 27 repositories with heavy duplication. Most are Rork-generated prototypes with no README, no CI, no branch protection, no useful tests, no license, and repeated code.

The canonical repository has the strongest foundation:

- SwiftUI + SwiftData.
- Clearer `Core`, `Features`, `Models`, and service boundaries.
- Existing build scripts.
- Supabase schema already present.
- More direct path to production iOS work.

## Migration Rule

Migrate product concepts, not generated files.

Allowed migration examples:

- Better onboarding copy.
- Paywall flow ideas.
- Diary, agenda, contraction timer, and community concepts as issues.
- Visual direction notes.

Blocked migration examples:

- Large copied SwiftUI views.
- Placeholder secret files.
- Duplicate Expo/Vite implementations.
- Any code with unsafe credential patterns.
